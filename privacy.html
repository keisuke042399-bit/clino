プライバシーポリシー

アプリ名：クリノメーター（Android アプリ・Web 版）
制定日：2026年11月1日

本ポリシーは、地質調査用アプリ「クリノメーター」（以下「本アプリ」）が扱う情報と、その取り扱い方法を説明するものです。

1. 要点

  • 本アプリは、測定値や位置情報を開発者や第三者のサーバーに送信しません。
  • 記録はすべて、利用者の端末の中にだけ保存されます。
  • 広告、アクセス解析、アカウント登録の仕組みはありません。

2. 本アプリが使う情報

情報使う目的と保存場所
端末の姿勢・方位（加速度センサー、地磁気センサー、ジャイロスコープ） 走向・傾斜・方位を計算して画面に表示するために使います。保存ボタンを押したときだけ、その時点の値を端末内の記録に保存します。
位置情報（緯度・経度・精度） 測定地点を記録に残すため、また真北基準での磁気偏角の補正（Android アプリ）に使います。利用者が許可した場合のみ取得し、保存ボタンを押したときに端末内の記録に保存します。
測定の記録 端末内（Android アプリはアプリ専用の保存領域、Web 版はブラウザの保存領域）にだけ保存されます。

Android アプリはインターネット通信の権限を持っておらず、外部と通信しません。

3. 記録の書き出し（CSV 出力）

「CSV出力」を押すと、記録を CSV ファイルとして端末に保存し、共有メニューを開きます。ファイルの送り先（メール、クラウドストレージなど）は利用者が選ぶもので、本アプリや開発者が自動で送信することはありません。送り先のサービスでの取り扱いは、そのサービスのプライバシーポリシーに従います。

4. 第三者への提供

本アプリは、利用者の情報を開発者が受け取ることがないため、第三者に提供・販売することもありません。

5. Web 版について

Web 版は GitHub Pages（GitHub, Inc.）で配信しています。ページを開く際の通信記録（IP アドレスなど）は、配信のために GitHub が取り扱う場合があります。詳しくは GitHub のプライバシーステートメントをご覧ください。測定値と位置情報は、Web 版でも端末の外へ送信されません。

6. 記録の削除

アプリ内の「全削除」で、すべての記録を削除できます。Android アプリをアンインストールした場合も、記録は削除されます。Web 版では、ブラウザのサイトデータを削除すると記録も削除されます。

7. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。また、年齢を含む個人情報を収集しません。

8. ポリシーの変更

本ポリシーを変更する場合は、このページで公開します。
